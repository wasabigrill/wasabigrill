- Push-swap project (C)
  
  I am given a stack of integers and I need to sort them using an additional stack. The goal is minimise the amount of operations to sort the number in stack A using an addition emtpy stack B with only stack operations (push element from one to the other, swap the top two element in one stack or both stack simultaneously, shift up or down one stack of both stack simultaneously).
  This projects involves low-level memorty management, input parsing, data structure using linked-list. Algroithm implementation was that I first find the longest increasing subsequence in stack A, then push the rest of the integers to stack B, finally use greedy cost to find the integer that cost minimum to insert it back to stack A at correct positon. This algorithm sort 500 numbers with ~5000 stack operations.
